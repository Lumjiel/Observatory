### 新工作流

| 步骤 | 操作 |
|------|------|
| 本地开发 | 改 `main` 分支，commit，push |
| 部署准备 | `git checkout server && git merge main && git push` |
| 服务器更新 | `git pull origin server && npm install && npm run build && pm2 restart` |
| GitHub 超时 | 本地 `git bundle create deploy.bundle server` → SCP → 服务器 `git fetch ... && git merge --ff-only` |
